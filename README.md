# JoyoseConfig-Get

从服务器拉joyose的teg_config

## 使用说明

默认压缩包内只保留这两个文件：

```text
[booster_config].json
[common_config].json
```
## 默认配置
$Device = "songyuan"  
$MiuiRegion = "CN"  
$Locale = "zh_CN"  
$Incremental = "4.0.5.0.AUTO"  
$MiuiVersionName = "V816"  
$BuildType = "stable"  
$AndroidRelease = "16"  

拉取其他设备配置一般只需要修改设备代号
